# Scope: Milestone M1 — UI/UX Foundation

## Objectives
- Initialize the Next.js project with Tailwind CSS and TypeScript in the workspace root.
- Establish a clean 80/20 visual design system (typography, spacing, color palette) configured in `tailwind.config.js`.
- Design and build the main user dashboard layout:
  - Header (minimal, branding, user session state placeholder).
  - Watchlist view (grid of movie cards containing title, poster, and rating).
  - Search/Filter inputs.
- Build the "Add Movie" modal/dialog containing a URL text field.
- Ensure the layout is fully responsive and passes verification on both desktop and mobile viewports.

## Interfaces

- Uses mock static movie watchlist data for rendering (interface contracts defined in `PROJECT.md`).
